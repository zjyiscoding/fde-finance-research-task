# 高难度版本 V2：两家城投信用资料核验与投委会放行门槛

## 任务提示词草案

你是一名固定收益/信用债研究员，为投委会准备淮北市建投控股集团有限公司与淮南建设发展控股（集团）有限公司的信用资料核查与阶段性放行建议。附件包含会议纪要、原始转记、修订记录、募集说明书、格式规范、研报和项目页面截图。请把附件当作一组互相可能冲突的原始工作底稿，建立可追溯的证据链，不得把整理稿、截图或推断写成正式公告。

最终交付必须同时包含：
1. 逐文件资料登记表：主体、文件全名、文件日期、文件类型、来源状态、定位信息、可证明事实和不能证明的事项。
2. 逐项债务事实表：有息债务、债券、银行贷款、非标、境外债、偿债资金池、融资成本、到期压力、担保、评级和政府支持边界；每一项给出来源、时点、口径、证据等级和冲突说明。
3. 冲突仲裁表：对同一事项的多个数字或表述，分别写出范围、时点、权威性、生效状态和是否可以比较；不得按“最新日期”直接裁决，也不得未经证据加总。
4. 资金压力与替代路径：在附件能够支持的范围内，分别构造基准、债务置换延迟、短期再融资受限三个情景；对无法计算的项目明确写“附件不足以计算”，说明缺少的原始数据，不得编造假设数字。
5. 投委会阶段性门槛：分别判断两家主体当前是“可以进入下一轮尽调”“仅可补证后进入”“当前不宜形成信用结论”中的哪一类，并把触发该判断的硬证据、反证和待补文件列清楚。不得给出买卖建议。
6. 最终输出一页以内的摘要，并附一份不超过十条的后续补证清单。所有关键数字、日期、单位、评级和状态必须能回到文件位置。

限制条件：
- 仅使用附件及附件明确给出的来源；不得联网补齐缺失公告，不得臆造正式公告。
- 保留会议口述、修订记录、募集说明书和截图之间的差异；同一数字必须标明公司口径、合并口径或产品口径及对应日期。
- 金额统一用亿元，比例保留%，日期具体到日；无法确认的内容标记“待核实”。
- 不能只写摘要，必须交付事实表、冲突表、情景判断和放行门槛。表格与摘要中的数字必须一致。
- 如果任何主体缺少形成阶段性判断所必需的正式财报、评级或公告原文，必须明确停止在“补证后进入”或“当前不宜形成信用结论”，不能用会议口述替代。

## 运行要求

请先读取全部附件并建立文件清单，再独立抽取事实、做口径仲裁、进行三情景判断、完成跨表一致性复核，最后输出完整交付物。不要把 Ideal Steps、Golden Response 或 Rubrics 当作输入。
