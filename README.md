# FDE Finance Research Task

公开协作仓库，用于保存这个金融投研任务的版本文件，以及与任务相关的研报、公告和会议纪要。

## 目录

- `versions/`：任务文件、模板和工作成果的版本记录
- `materials/reports/`：研报与研究资料
- `materials/announcements/`：公司公告、监管公告和项目通知
- `materials/minutes/`：会议纪要、访谈纪要和讨论记录
- `docs/`：项目说明、字段规范和研究笔记
- `scripts/`：下载、整理、校验和分析脚本

## 协作方式

1. 每个重要版本使用独立目录或清晰的版本号保存，不覆盖历史文件。
2. 原始材料尽量保留来源、发布日期、链接、获取时间和文件哈希。
3. 修改已有材料时，通过 Pull Request 说明变更原因和影响。
4. 不提交密码、令牌、个人联系方式、未脱敏客户数据或不适合公开的内部文件。

## 材料版权与公开范围

本仓库公开可见。研报、公告和会议纪要如果来自第三方，仍受其原始版权、许可和访问限制约束；提交前请确认公开和再分发权限。当前不对第三方材料统一授予新的许可证。

## 当前状态

仓库已包含当前题目草案、高难度版本、运行评估记录和用户指定的研报、公告目录及会议材料。后续新增版本请保留来源记录，并在确认公开权限后提交。
