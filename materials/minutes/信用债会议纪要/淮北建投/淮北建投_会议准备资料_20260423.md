## 二、历史沿革

- **2008年4月**：经淮北市人民政府办公室批准（淮政办秘〔2008〕39号），由淮北市国资委出资6,000万元设立，初名"淮北市建投控股有限公司"
- **2008年5月**：公司名称变更为**淮北市建投控股集团有限公司**
- **2008年9月**：国资委将国有资产运营、公用事业资产运营、供水实业、排水四家公司股权无偿划拨，资本公积转增10亿元，注册资本增至106,000万元
- **2011年3月**：货币出资置换资本公积转增注册资本，出资方式变更
- **2015年4月**：股东名称由"淮北市国有资产管理委员会"更名为"淮北市国有资产监督管理局"
- **2015年10月**：第二次增资3亿元，注册资本增至136,000万元
- **2017年3月**：第三次增资4.69亿元，注册资本增至182,900万元
- **2019年3月**：股东名称变更为"淮北市人民政府国有资产监督管理委员会"；同时以未分配利润转增30亿元，注册资本增至482,900万元
- **2019年5月**：第五次增资，以2018年未分配利润转增34亿元，注册资本增至822,900万元
- **2023年5月**：第六次增资（利润转增+货币出资4,000万元），注册资本增至826,900万元
- **2023年9月**：第七次增资5,000万元，注册资本增至831,900万元
- **2024年3月**：第八次增资40亿元，注册资本增至1,231,900万元
- **2024年4月**：第九次增资1.8亿元，注册资本增至1,249,900万元
- **2024年12月**：第十次增资1亿元，注册资本增至1,259,900万元
- **2025年3月**：第十一次增资1亿元，注册资本增至**1,269,900万元**（工商变更办理中）

> 注：经16年11次增资，注册资本从初始6,000万元增长至126.99亿元，增长逾212倍，历次增资均由国资委以货币出资或利润转增方式完成。

## 四、经营范围与主营业务

### 经营范围
参与城市开发、公用服务建设、交通运营管理、文化旅游开发，城市基础设施、基础产业、基础农业、能源、交通及市政公用事业项目投资、融资、建设、运营、管理；从事授权范围内国有资产经营管理和资本运作，实施项目投资管理、资产收益管理、产权监督管理、资产重组和运营；参与房地产开发。

### 主营业务板块

**（一）商品销售板块**（第一大业务，占收入约70%）
- 主要从事煤炭、焦炭、钢材等大宗商品贸易，毛利率约2.8%-8.6%，利润水平低
- 2024年收入163.97亿元，占比69.60%；毛利率2.79%

**（二）棚户区改造工程板块（政府购买）**（第二大业务，占收入约18%）
- 通过政府购买服务协议方式承接棚改工程，2016年后采用该模式
- 2024年收入43.24亿元，占比18.35%；毛利率14.14%

**（三）保障性安居房板块**（占收入约5%）
- 2024年收入12.30亿元，占比5.22%；毛利率42.08%

**（四）市场化施工板块**（占收入约2.5%）
- 承接市场化基础设施建设项目
- 2024年收入6.01亿元，占比2.55%；毛利率43.97%

**（五）租赁及其他**
- 租赁（标准化厂房等）：毛利率89.42%，高利润但规模小
- 排水、供水：毛利率42.78%
- 担保费：毛利率100%

## 九、风险提示

### 财务风险
1. **有息债务规模庞大**：有息负债828亿元，财务负担较重，利息支出压力大（2024年财务费用约5.5亿元）
2. **短期偿债压力**：2024年末短期借款51.84亿+应付票据43.07亿+一年内到期非流动负债189.87亿，短期偿债金额较大
3. **应收账款持续增长**：2024年末180.84亿元，虽主要为政府类款项但回款周期较长
4. **存货规模大**：2024年末约451.88亿元（占总资产29.51%），主要为土地使用权，存在一定的跌价风险
5. **受限资产较大**：149.47亿元（占总资产9.76%），影响资产流动性
6. **经营性现金流波动**：三年经营现金流分别仅0.49亿、17.48亿、24.46亿，对约830亿有息债务偿付保障有限
7. **盈利能力波动**：净利润从22亿降至20亿，净利率下降，主要系商品销售板块盈利能力弱（毛利率仅约3%）
8. **政府补贴占净利润比例较高**：近三年分别为25.48%、11.97%、6.79%，政策变化有不确定性

### 经营风险
1. **大宗商品贸易风险**：商品销售占收入约70%，但毛利率仅约5%，受国内外大宗商品价格波动影响大
2. **工程委托方支付能力较弱**：淮北市经济收入在安徽省内排名中下游，政府支付能力有一定压力
3. **对外担保代偿风险**：对外担保116.46亿元，若被担保企业出现困难将影响发行人
4. **中心湖带经营权收益不确定**：评估价值约110亿元，未来收益受旅游市场影响
5. **房地产权证部分未办理**：投资性房地产103.85亿元中部分房屋建筑物尚未办理完权证

### 政策与区域风险
1. **地方财政收入影响大**：收入主要对手方为淮北市财政局，区域财力一般，经济处于转型期
2. **政府债务政策变化风险**：地方政府债务政策趋严，相关业务受影响
3. **土地政策变动风险**：持有大量土地资产，受土地政策影响较大

## 十、竞争优势与战略价值

### 核心优势
1. **唯一综合性城市运营平台**：发行人系淮北市政府批准设立的市属唯一综合性城市建设运营主体，承担城市基础设施的投融资、建设及经营管理，具有不可替代的战略地位
2. **政府股东背景强**：100%国有独资，实际控制人为淮北市国资委，国有资本多次增资（16年11次），政府支持力度较大
3. **资产规模大、资质全**：总资产1,531亿元，拥有完整的城市运营资质体系，业务覆盖建设、供水、文旅、交通、担保等多个领域
4. **融资渠道畅通**：银行总授信998.32亿元，未使用额度475.70亿元，在银行间市场有活跃的发债记录（存续债291亿元）
5. **货币资金充足**：截至2025年3月末持有货币资金108.81亿元，其中可自由动用58.39亿元

### 主要挑战
- 商品贸易业务虽规模大，但毛利率极低（约3%），实质贡献有限
- 有息负债规模持续高位（逾830亿元），财务杠杆较高（资产负债率约64%）
- 区域经济体量偏小，政府财力一般，对城建项目的回款支撑能力有限

## 十一、专有名词解释

| 术语 | 说明 |
|----|-----|
| MTN | 中期票据（Medium Term Note），通常为1-10年，在银行间市场发行 |
| PPN | 定向工具（Private Placement Note），银行间市场非公开定向发行 |
| 棚改 | 棚户区改造，政府主导的城市老旧房屋改造项目，政府购买服务模式下具有较确定的回款来源 |
| 有息债务 | 短期借款+一年内到期非流动负债+长期借款+应付债券+有息长期应付款及其他有息负债 |
| 资产负债率 | 负债合计 / 资产总计，反映整体杠杆水平 |
| 名股实债 | 表面上以股权方式引入资金，实质上具有固定回报、到期回购义务，本质为债务融资 |
| 受限资产 | 已用于质押、抵押或存出保证金的资产，不可自由处置 |
| 簿记建档 | 债券发行时收集投资者订单、确定发行规模和利率的过程 |
| 上海清算所 | 上海清算所，全国银行间债券市场债券登记托管机构 |
